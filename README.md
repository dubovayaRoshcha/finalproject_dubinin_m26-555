# ValutaTrade Hub

ValutaTrade Hub - приложение на Python для управления виртуальным валютным портфелем. Программа позволяет регистрировать пользователей, работать с кошельками, просматривать портфель и получать актуальные курсы валют.

Поддерживаемые валюты:
- Фиатные: USD, EUR, RUB.
- Криптовалюты: BTC, ETH.

Курсы загружаются из двух внешних API:
- **CoinGecko** - криптовалюты.
- **ExchangeRate-API** - фиатные валюты.

## Установка и запуск

```bash
uv sync
```

```bash
uv run valutatrade
```

## Настройка API-ключа

Для полчения курсов фиатных валют необходимо зарегистрироваться на [ExchangeRate-API](https://www.exchangerate-api.com/) и получить API-ключ.

Ключ хранится в переменной окружения `EXCHANGERATE_API_KEY` и не должен добавляться в исходный код.

## Команды приложения

- `register --username user --password 1234` - регистрация пользователя.
- `login --username user --password 1234` - вход в аккаунт.
- `show-portfolio` - просмотр портфеля в USD.
- `show-portfolio --base EUR` - просмтр портфеля в EUR.
- `buy --currency BTC --amount 0.01` - покупка валюты.
- `sell --currency BTC --amount 0.005` - продажа валюты.
- `get-rate --from BTC --to USD` - получение курса валют.
- `update-rates` - обновление курсов из обоих API.
- `update-rates --source coingecko` - обновление криптовалют.
- `update-rates --source exchangerate` - обновление фиатных валют.
- `show-rates` - просмотр всех курсов из кеша.
- `show-rates --currency BTC` - просмотр курса выбранной валюты.
- `show-rates --top 2` - две самые дорогие криптовалюты
- `show-rates --base EUR` - просмотр курсов относительно EUR.
- `help` - список команд.
- `exit` - выход из приложения.

Для операций `buy`, `sell` и `show-portfolio` необходимо предварительно выполнить `login`.

Покупка увеличивает баланс выбранной валюты без списания USD, а продажа уменьшает баланс без начисления USD. Стоимость операций рассчитывается в долларах по текущему курсу.

## Хранение данных

Для хранения информации используются JSON-файлы:

- `data/users.json` - данные пользователей и хеши паролей.
- `data/portfolios.json` - валютные кошельки и их балансы.
- `data/rates.json` - кеш актуальных курсов.
- `data/exchange_rates.json` - история обновлений курсов.

Курсы сохраняются относительно USD, например `BTC_USD`, `EUR_USD`. Пересчёт между другими валютами выполняется через доллар.

## Кеширование и TTL

Используется локальный кеш `rates.json`, поэтому при каждой операции не трбуется обращаться к внешним API.

Срок актуальности курсов задаётся в `pyproject.toml`:

```toml
rates_ttl_seconds = 300
```

TTL составляет 300 секунд (5 минут).

При запросе курса программа проверяет время последнего обновления необходимой валютной пары. Если курс устарел, выводится сообщение с предложением выполнить `update-rates`

Команда `show-rates` позволяет посмотреть сохранённые курсы, даже если срок их актуальности уже истёк.

При недоступности одного API обновление другого продолжается. Ранее сохранённые курсы не удаляются. История защищена от дублирования записей с одинаковыми идентификаторами.

## Parser Service

Parser Service отвечает за получение и сохранение курсов валют.

Основные компоненты:

- `config.py` - настройки API, валют и интервалов.
- `api_clients.py` - клиенты CoinGecko и ExchangeRate-API.
- `updater.py` - объединение и обновление курсов.
- `storage.py` - сохранение кеша и истории.
- `scheduler.py` - автоматическое обновление курсов.

Ручное обновление выполняется командой:

```text
update-rates
```

## Автоматическое обновление курсов

Для запуска планировщика в отдельном терминале:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler
```

Планировщик выполняет первое обновление сразу после запуска, затем повторяет его с интервалом из `ParserConfig`:

```python
UPDATE_INTERVAL = 300
```

## Логирование

В приложении реализовано логирование операций и ошибок.

Логи сохраняются в следующих файлах:

- `logs/actions.log` - операции покупки, продажи и возникающие ошибки.
- `logs/parser.log` - обновление курсов, результаты запросов к API и ошибки Parser Service.
